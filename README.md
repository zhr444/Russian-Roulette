# 🎲 Русская Рулетка — 6-Chamber Revolver

**Классическая русская рулетка с 6-зарядным барабаном — прямо в браузере.**

Один `index.html` + `style.css` + `script.js`. Пять языков, две темы, три режима игры, процедурный звук, анимированный барабан, живой журнал событий и статистика, которая сохраняется между сессиями. Никаких фреймворков, сборщиков и внешних ассетов.

---

## 🎮 Возможности

- **Три режима игры:**
  - 🎯 **Одиночный** — играешь против вероятности, крутишь барабан и спускаешь курок на выживание.
  - 🤖 **Против Дилера (ИИ)** — бот сам решает, крутить барабан заново или сразу стрелять, в зависимости от текущего риска.
  - 👥 **2 Игрока** — играете по очереди на одном экране (Pass & Play).
- **Выбор числа боевых патронов** — от 1 до 5 из 6 камор. Чем больше пуль, тем выше риск.
- **Живой индикатор риска** — процент вероятности выстрела пересчитывается после каждого холостого щелчка.
- **Анимированный 6-зарядный барабан** — плавное вращение через CSS `transform: rotate()`, с визуальными состояниями камор:
  - ⚪ Неизвестно
  - 🟢 Проверена (холостая)
  - 🟡 Боевой патрон (раскрывается при проигрыше)
  - 🔴 Выстрел (вспышка + тряска экрана)
- **Процедурный звук на Web Audio API** — серия металлических кликов при вращении, щелчок бойка, взрыв выстрела. Ноль mp3-файлов.
- **5 языков интерфейса** — Русский, English, Қазақша, Español, Deutsch. Полная локализация, включая плюрализацию и даты.
- **Две темы** — Тёмная и Светлая, переключаются мгновенно.
- **Виджет реального времени** — часы и дата адаптируются под выбранный язык через `Intl.DateTimeFormat`.
- **Статистика в localStorage** — успешные ходы, поражения, текущая серия, рекорд серии. Сохраняется между сессиями.
- **Журнал событий** — каждая прокрутка, каждый щелчок и каждый выстрел фиксируются с таймкодом.
- **Вспышка при выстреле** — радиальный эффект на весь экран + shake всей сцены.
- **Адаптивность** — на планшетах и смартфонах панели перестраиваются в одну колонку.
- **A11y** — `aria-live`, `sr-only`, `aria-label`, `role="status"` для скринридеров.

## 🚀 Быстрый старт

### Вариант 1 — просто открыть

```
git clone <репозиторий>
cd russian-roulette
```

Открой `index.html` двойным кликом в браузере.

> ⚠️ Для корректной работы `AudioContext` лучше запускать через локальный HTTP-сервер.

### Вариант 2 — локальный сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# или Node.js
npx serve .
```

Затем открой [http://localhost:8000](http://localhost:8000).

## 🕹️ Как играть

1. **Выбери режим** — Одиночный, против Дилера или 2 Игрока.
2. **Выбери количество боевых патронов** — от 1 до 5 (по умолчанию 1).
3. Нажми **«🔄 Крутить барабан»** — камор случайно сдвигается под боёк.
4. Нажми **«💥 Спустить курок»** — узнаешь, была ли камора пустой или боевой.
5. **Пустая камора** — повезло, барабан проворачивается к следующей каморе.
6. **Боевой патрон** — выстрел, вспышка, тряска. Тот, кто нажал на курок, теряет раунд.
7. Если все пустые каморы пройдены — победа! Можно начинать **новую партию**.

### Правила риска

- Чем меньше непроверенных камор осталось, тем выше шанс выстрела.
- После ручной прокрутки барабана все отметки сбрасываются (позиция снова случайна).
- **Дилер (ИИ)** учитывает текущий риск: если он выше 45% — с вероятностью 50% перекрутит барабан заново.

### Основные модули в `script.js`

| Модуль | Назначение |
|--------|-----------|
| `I18N` | Словарь переводов на 5 языков (с функциями для динамических строк) |
| `STORAGE_KEYS` | Константы ключей `localStorage` |
| `SoundEngine` | Процедурный звук: клики, щелчок бойка, выстрел |
| `state` | Глобальное состояние: язык, тема, режим, каморы, статистика |
| `els` | Ссылки на все DOM-элементы |
| `initNewRound()` | Новая партия: случайная раскладка патронов, случайная позиция |
| `spinToChamber()` | Плавное вращение барабана к нужной каморе (CSS-трансформация) |
| `stepNextChamber()` | Пошаговый поворот на 60° |
| `handleSpinAction()` | Обработка прокрутки: сброс отметок, новая случайная позиция |
| `handleTriggerAction()` | Обработка выстрела: холостой или боевой |
| `advanceTurn()` | Передача хода (для режимов Bot и PvP) |
| `calculateCurrentRisk()` | Расчёт вероятности выстрела |
| `updateRiskMeter()` / `updateTurnBanner()` / `updateButtonsState()` | Обновление UI |
| `setStatus()` / `addLogEntry()` | Статусное сообщение и запись в журнал |
| `applyTheme()` / `applySound()` / `applyLanguage()` | Переключение настроек |
| `bootstrap()` | Инициализация при загрузке |

## 🌐 Локализация

Поддерживаются 5 языков с полным перев��дом всех UI-строк:

| Язык | Код | Локаль |
|------|-----|--------|
| 🇷🇺 Русский | `ru` | `ru-RU` |
| 🇺🇸 English | `en` | `en-US` |
| 🇰🇿 Қазақша | `kk` | `kk-KZ` |
| 🇪🇸 Español | `es` | `es-ES` |
| 🇩🇪 Deutsch | `de` | `de-DE` |

Выбранный язык сохраняется в `localStorage` и применяется при следующем запуске. Также от него зависит формат даты и времени в верхнем виджете.

### Как добавить язык

1. Добавь новую ветку в объект `I18N` в `script.js` (скопируй структуру `ru`).
2. Добавь `<option>` в селектор `#langSelect` в `index.html`.
3. Всё — остальная логика автоматически подхватит новый язык.

## 🎨 Темы

Тёмная и светлая темы реализованы через `data-theme` на `<html>` и CSS Custom Properties. Все цвета — переменные `--bg-*`, `--text-*`, `--accent-*`, `--cylinder-*`. Переключение мгновенное, без перезагрузки.

### Как добавить тему

1. Добавь новый блок `[data-theme="my-theme"] { ... }` в `style.css` с переопределением переменных.
2. Измени логику `applyTheme()` в `script.js`, чтобы циклически переключать темы.
3. Добавь иконку и перевод.

## 💾 Сохранения

Всё хранится в `localStorage` под ключами:

| Ключ | Что хранится |
|------|-------------|
| `rr_theme_v1` | Текущая тема (`dark` / `light`) |
| `rr_lang_v1` | Текущий язык (`ru` / `en` / `kk` / `es` / `de`) |
| `rr_sound_v1` | Включён ли звук (`true` / `false`) |
| `rr_stats_v1` | Статистика (JSON: `survived`, `deaths`, `streak`, `best`) |

Сброс статистики — кнопка «Сбросить» в блоке «Статистика». Полный сброс — очистка `localStorage` вручную через DevTools.

## 🐛 Известные особенности

- Звук инициализируется только после первого действия пользователя — так требует браузер.
- Если `localStorage` отключён (приватный режим), настройки не сохранятся, но игра продолжит работать.
- При открытии файла напрямую (`file://`) некоторые браузеры могут блокировать `AudioContext` — используй локальный сервер.
